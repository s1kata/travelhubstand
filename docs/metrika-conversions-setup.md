# Travel Hub — настройка «Конверсии» в Метрике (113554694)

Страница отчёта: [Конверсии](https://metrika.yandex.ru/stat/conversion_rate?id=113554694)

## 1. Параметры отчёта (верхняя панель)

| Элемент | Рекомендация |
|--------|----------------|
| Период | **7–14 дней** (не «Сегодня») — иначе воронка шумная |
| Сегмент | Создать **B2C**: URL не содержит `for-operators`, не содержит `#tvtourid` |
| Метрики | **Конверсия** + **Достижения** + при необходимости **Целевые визиты** |
| Группировка | **По дням** (не по минутам) для воронки |

## 2. Цели уже заведены (иерархия на экране)

Код сайта шлёт `ym(..., 'reachGoal', '<id>')`. В интерфейсе у целей русские названия, идентификатор JS — латиница.

| JS-идентификатор (`reachGoal`) | Название в Метрике (как в списке) |
|-------------------------------|-----------------------------------|
| `lead_ok` | Успешная заявка |
| `search_start` | Начало поиска туров или отелей на главной |
| `search_results_shown` | Показ результатов поиска на главной |
| `search_error` | Ошибка поиска на главной |
| `tour_detail_open` | Открытие карточки тура |
| `booking_form_open` | Открытие формы бронирования |
| `card_booking_lead_ok` | Заявка из бронирования на карточке тура |
| `country_page_open` | Открытие страницы страны |

Полный каталог для API: `backend/config/metrika_goals_catalog.php`

## 3. Добавить 3 цели по перелётам (после деплоя `tourvisor-flight-pick.js`)

**Добавить цель** → **Параметры** (или «JS-событие») → идентификатор **точно как в коде**:

| Идентификатор | Название цели |
|---------------|---------------|
| `flight_load_ok` | Перелёт подгружен на карточке |
| `flight_load_fail` | Перелёт не подгрузился |
| `flight_stub_lead` | Лид: перелёт не загрузился (CTA) |

Автосоздание (OAuth `metrika:write`):

```bash
php backend/scripts/metrika_sync_goals.php --dry-run
YANDEX_METRIKA_OAUTH_TOKEN=y0_... php backend/scripts/metrika_sync_goals.php
```

## 4. Ключевые цели (Настройки счётчика → Цели)

Отметить **ключевой**:

1. `lead_ok` — Успешная заявка  
2. `card_booking_lead_ok` — заявка с карточки  
3. `search_results_shown` — дошли до выдачи  
4. `search_error` — диагностика обрыва  

## 5. Воронка B2C на вкладке «Конверсии»

Кнопка **«Все цели»** → оставить только шаги (порядок сверху вниз):

1. Начало поиска… (`search_start`)  
2. Показ результатов… (`search_results_shown`)  
3. Открытие карточки тура (`tour_detail_open`)  
4. Открытие формы бронирования (`booking_form_open`)  
5. Успешная заявка (`lead_ok`)  

Дополнительно смотреть **flight_load_fail / flight_load_ok** — доля fail показывает проблему с перелётами.

## 6. Составная цель (опционально)

**Мультицель** или **Составная цель**:  
`search_start` → `search_results_shown` → `booking_form_open` → `lead_ok`  
(для отчёта «сквозная конверсия поиска» в Директе).

## 7. Проверка

1. На сайте принять cookies (иначе Метрика не грузится).  
2. Консоль: `ym(113554694, 'reachGoal', 'search_start')` — в Метрике **Онлайн** → цели.  
3. Через 15–30 мин — цифры в «Конверсии».
