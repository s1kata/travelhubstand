# Цели Яндекс.Метрики

**Счётчик:** `113554694`  
**Идентификатор сайта:** `travelhub63.ru`

В проекте используется этот же ID и параметры из нового скрипта: Вебвизор, карта кликов, ecommerce через `dataLayer`, отслеживание ссылок и точный отказ. Счётчик загружается только после согласия пользователя на аналитические cookies. Не вставляйте дополнительный немедленно запускающийся экземпляр кода: это создаст дубли счётчика и обойдёт действующую проверку согласия.

## Как добавить цель в интерфейсе

Для каждого идентификатора из таблиц:

1. Откройте счётчик `113554694` в Яндекс.Метрике.
2. Перейдите в **Настройки → Цели → Добавить цель**.
3. Выберите **JavaScript-событие**.
4. В поле идентификатора цели вставьте значение из столбца **Идентификатор цели** без кавычек.
5. Сохраните цель. Регистр и подчёркивания важны.

События начинают поступать только после публикации соответствующего кода и согласия пользователя на аналитические cookies. Пользовательские параметры события (например, `source`, `page_type`, `result_count`) передаются отдельно и не являются идентификаторами целей.

## Как читать конверсии

- Для общей конверсии по заявкам используйте `lead_ok`.
- Для отдельного анализа бронирований можно использовать `tour_booking_success` и `card_booking_lead_ok`. Не складывайте их с `lead_ok`: успешное бронирование также отправляет общую цель `lead_ok`.
- `promo_lead_success` — дополнительная цель для отдельного отчёта по формам акций; она также может сопровождаться `lead_ok`.
- Цели `*_view`, `*_open`, `*_click`, `*_start`, `*_shown` описывают шаги пути, а не завершённые заявки.
- В параметры целей не включаются ФИО, телефон, email и другие персональные данные.
